# Hailey Ek Portfolio

A photography and content creation portfolio.

## Publish on GitHub Pages

1. Download and unzip the portfolio package.
2. Open your public `haileyek.github.io` GitHub repository.
3. Upload `index.html` and the entire `images` folder to the root of the repository.
4. Commit the changes.
5. Under Settings > Pages, choose Deploy from a branch, `main`, and `/ (root)` if not already set.
6. Visit https://haileyek.github.io after deployment.

## Before sharing

Add your contact details, replace the Content Creation placeholder with actual projects, and review the suggested photo titles and About copy. Confirm permission to publicly display recognizable people, especially children.
